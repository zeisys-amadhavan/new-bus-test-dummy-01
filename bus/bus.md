# This repository uses the Execution Bus (live test target)

The workflows in `bus/workflowN.md` define one cycle each; a request issue made from `bus/request-template.md` asks for cycles. The bus compiles each workflow onto the ledger branch at install and runs cycles against request issues. The cardinal rules of the bus apply; the owner merges.
