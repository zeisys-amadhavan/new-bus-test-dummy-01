# README criteria (live test yardstick)

Score the README out of 100, unrounded, on three criteria. Report each criterion's score and the weaknesses you see.

| Criterion | Weight | What earns points |
|---|---|---|
| Purpose | 40 | The first paragraph says what the repository is for in one or two plain sentences. |
| Getting started | 40 | A reader can run or use the project from the instructions given, in order. |
| Clarity | 20 | Short sentences, no unexplained jargon, headings that match their content. |
